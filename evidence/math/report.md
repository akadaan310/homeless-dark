## Implemented contracts and limits

**HD-015/016/087 — established numerical methods [K], newly implemented code [C].** `Dark.Numerics.Geodetic`, `Vector3d`, `Geodesy`, and `LocalEnuFrame` use WGS84 (`a=6378137 m`, inverse flattening `298.257223563`), geodetic degrees and explicit ellipsoid height. Longitude canonicalizes to `[-180,180)`. ECEF inversion has a 16-iteration ceiling, an explicit nonconvergence exception, and a supported height domain of -100 km to +1,000,000 km; it refuses the undefined Earth center. A longitude of zero is selected at exact ECEF poles, where longitude is geometrically indeterminate. A maximum one-micrometer endpoint correction addresses floating point roundoff. Local ENU frames require a declared radius no larger than 1000 km and refuse coordinates outside it. They do not shift Unity bodies, cameras or temporal effects. Tests use angular tolerance `1e-9 degrees`, ordinary reconstructed height `1e-5 m`, local round trips `2e-8 m`, and explicit tighter literal expectations where appropriate; these are observed fixture tolerances, not global error theorems.

**HD-025/087 — Hamilton/largest-remainder integer apportionment [K].** `IntegerApportionment.Allocate(ulong total, IReadOnlyList<PopulationWeight>)` uses exact `BigInteger` intermediate arithmetic, at most 4096 shards, nonnegative integer weights, positive weight sum, unique stable shard IDs, and ordinal ID tie breaking. It returns a read-only mapping whose sum exactly equals the chosen parent total, including `ulong.MaxValue`. Hierarchical use must preserve each chosen parent total. No demographic dataset is ingested here, no fractional estimate conversion policy is silently chosen, and this allocation does not realize synthetic people, create identity ranges, reconcile travel, or demonstrate planetary population coverage.

**HD-056/058/059/087 — bounded grammar constructions [C] and relational inverses [K].** `TashkilResolver` stores a declared skeleton, a fixed structural level, at most 256 readings, and at most 32 context reads per reading. Unknown observations preserve all compatible readings. Contradictions remove readings; an empty fiber returns `Unreadable`. Multiple candidates return `Ambiguous`, ordered by declared rank then ordinal identity; selecting a candidate requires an explicit admitted reading ID. Pointing never changes the structural level or skeleton. Unrelated context does not reroll identity. Completeness is only over the explicitly registered finite fiber; no linguistic completeness is claimed. Folding/alphabet towers, all nine In-Grammar pillars, and peritro are not implemented by this increment.

`NumberCell` distinguishes value/plenum, zero/nullum, missing/vacuum complebile, forbidden/lacuna and foreign/xenocella. Only the first two expose numeric values. `IntegerConverse.Divide` solves `b*c=a` over **integers**, with operands limited to 512 signed bytes; `1/0` and `7/2` have image failure, `0/0` has kernel failure with every integer a preimage, and `0/1` uniquely returns zero. It does not invent a rational or infinity. `DivideMod` exhaustively enumerates `Z/n` for `1<=n<=4096`, returning every preimage, with no implicit branch selection. Infinite solution descriptions remain separate from finite lists and the five cell states.

**HD-063/064/065/087/091 — mathematical boundary rewrite [C].** `PlateWorld` is an immutable snapshot with exactly two plates, 2–256 preserved nodes, at most 512 simple undirected edges, and at most 256 point occupants/objects. The explicit rewrite formalism replaces one cross-plate boundary edge while preserving the external node, node identities and references; it optionally rotates one plate's local embedding. This is not represented as a general DPO implementation or proof. Complete component comparison distinguishes changed reachability from changed adjacency alone. Requests check exact revision, bounded rotation/timing, work units and application conditions before constructing a result. Refusal returns the identical input snapshot plus a clause-linked diagnostic. Caller arrays/maps are copied; public collections are read-only.

Affected occupants use exactly one declared policy: refuse while occupied, mathematical rigid carriage, or explicit witnessed relocation with a valid destination for **every** affected point entity. Either-side boundary straddlers are conservatively refused. Carriage witnesses expose an analytic continuous rotation curve and retain origin/destination, authority-provenance reference and ticks. A provenance string is **not authentication**. The effect-authority layer must authenticate/admit shared writes separately.

Every success says `mathematical-snapshot-admitted; physical-validation-NOT_RUN`; `RewriteWitness.PhysicalValidation` is always `NOT_RUN`. A curve does not certify clearance, velocity safety, rigidbody motion, or destination readiness. A physical adapter must independently validate swept collision/velocity, attachments, seats/vehicles, cameras, audio and nav links before admitting an embodied operation. This kernel must not be used to instantaneously rotate Unity bodies through obstacles.

An inverse requires the exact resulting snapshot object and retained before/after state. It restores graph/embedding/occupant mathematical state at a **new** monotonically increasing revision, rejects stale/foreign/repeated witnesses, and labels the operation as an inverse. It does not erase history or claim rollback/compensation equivalence. Inverse physical transport requires a fresh plan; its transport list is intentionally empty and explicitly labeled as such. The in-process witness is not a durable serialized save format. Nested plates, attachment relationships, stale observer knowledge, route repair, source-anchored Tampa graph integration, concurrency arbitration and crash recovery remain unimplemented in this lane. The included graph fixture is a synthetic three-node illustration, not a measured Tampa street graph.
