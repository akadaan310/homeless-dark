4. **Non-destructive migration:** verify status before edits, preserve all source history; never force-push; build under a named branch unless owner policy and collaborators allow safe integration.
5. **Progressive verification:** `PASS` requires executed evidence; `NOT_RUN` is not pass; a screenshot must be tied to a real compiled source revision.
